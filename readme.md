# Simple Git Sync

一个用于 Obsidian 桌面端仓库的轻量 Git 同步插件。它把自动提交（可选）、拉取和推送作为彼此独立的操作，并尽量将异常留在 Git 历史中，而不是在知识库中制造冲突副本或孤立分支。

## 能做什么

- 可选的定时自动提交，默认关闭；同步间隔与提交间隔互不绑定。
- 定时或手动执行拉取与推送；自动识别当前分支和远程仓库，也可在设置中指定。
- 真正的内容冲突采用两阶段提交：先在合并提交中保留较早版本，再以普通提交恢复较晚版本。因此两侧历史会汇合，两个版本也都可从主线历史复查。
- 拉取前清理 Git index 的“幻影修改”，并只对会阻塞合并的文件建立精确的预合并提交。
- 为网络 Git 操作设置超时；处理陈旧 `.lock` 文件；对 LFS 对象不可取得的场景提供指针优先的兜底合并。
- 对 Obsidian 的机器本地状态文件设置 `skip-worktree`，避免把界面布局等本机状态带入同步。

## 安装

1. 下载本仓库的 `main.js` 与 `manifest.json`。
2. 在目标 Obsidian vault 中创建目录：`.obsidian/plugins/simple-git-sync/`。
3. 将两个文件复制到该目录，然后在 Obsidian 的“社区插件”中启用 **Simple Git Sync**。
4. 在插件设置中确认同步间隔、远程仓库和分支。首次使用建议先手动运行一次“同步”，确认 Git 身份、认证和远程访问均正常。

本插件仅支持桌面端 Obsidian，要求 Obsidian 1.4.0 或更高版本，并依赖系统可用的 Git。

## 使用边界

自动同步降低了常规操作成本，但不替代备份、代码审查或对重要冲突的人为判断。两阶段冲突处理依据 Git 提交时间排序；多机器时钟明显漂移时，应复查相应的两次合并提交并按需恢复内容。

## 配置与数据

插件设置由 Obsidian 保存在 vault 本地的 `data.json`。该文件含本机的同步偏好，不应提交到本仓库。
